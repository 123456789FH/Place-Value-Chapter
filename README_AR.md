# مدينة الأعداد | رحلة الإتقان — V1.5

نسخة أولية وظيفية لمراجعة الفصل الأول: القيمة المنزلية للصف الثالث الابتدائي.

## ما يعمل الآن
- شاشة رئيسية.
- بوابة الطالب.
- خريطة ٩ مهارات.
- داخل كل مهارة: أفهمها، أجرّبها، أتدرّب، أصلح الخطأ، أتحدّى، بطاقة الإتقان.
- بنك أسئلة مولد محليًا دون API.
- حفظ أفضل نسبة لكل مهارة عبر LocalStorage.
- بوابة المعلم: الفكرة في دقيقة، نموذج، نشاط صفّي، تحدي السبورة، الخطأ الشائع، بطاقة خروج.
- تحدي فصل شامل.
- عيادة الأخطاء.
- وضع عرض للمعلم.
- تصميم متجاوب للجوال والآيباد والكمبيوتر.
- بدون موسيقى أو مؤثرات صوتية.
- PWA أولية ودعم العمل دون اتصال بعد أول تحميل ناجح.

## تشغيل محلي
افتح `index.html` مباشرة، أو شغّل خادمًا محليًا بسيطًا.

## الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا.
2. ارفع جميع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع.
3. من Settings → Pages اختر Deploy from a branch.
4. اختر `main` و `/root`.
5. انتظر ظهور رابط GitHub Pages.

## ملاحظة
الإصدار V1 يركز على البنية التعليمية والتفاعل الأساسي. يمكن في الإصدار التالي إضافة:
- شخصيات مرشدة.
- رسوم 3D أغنى.
- شهادات.
- تصدير نتائج.
- وضع فرق صفية كامل.
- أسئلة أكثر لكل مهارة.


## إضافات V1.1
- إدراج شعار ملتقى التعليم التفاعلي في الهوية وأيقونة التطبيق.
- إعادة بناء «برج القيمة المنزلية» كمختبر ثلاثي المهام:
  1. بناء العدد بالسحب والإفلات أو اللمس.
  2. تحديد المنزلة والقيمة.
  3. اختيار الصيغة التحليلية.
- زر «ساعدني» يوجّه الطالب دون إعطاء الإجابة كاملة من البداية.
- دعم اللمس إلى جانب السحب ليعمل المختبر على الجوال والآيباد.
- إضافة زر «ابدأ مراجعة صفية» في بوابة المعلم بمسار من ٥ خطوات.
- تحسين بصري لبطاقة برج القيمة المنزلية.


## إضافات V1.2
- استخدام شخصيتي **راشد وبسمة** داخل الشاشة الرئيسية وبوابة الطالب.
- جعل الواجهة أكثر بهجة وملاءمة للأطفال مع تحسينات لونية وبطاقات ألطف.
- إضافة بطاقة ترحيبية للطالب وفقاعة حديث على الرئيسية.
- إضافة زر عائم للمساعدة ورسائل تشجيعية من راشد وبسمة.
- تحسين مظهر البطاقات والمحطات لتبدو أكثر حيوية.


## إضافات V1.3
- إعادة تصميم **الصفحة الرئيسية بالكامل** بشكل طفولي مبهج وواضح.
- تكبير **راشد وبسمة** وإبرازهما كدليلين للرحلة.
- خلفية مدينة مرحة أكثر: شمس، سحب، بالونات أرقام، طريق، وبيوت تمثل المحطات.
- إضافة قسم **«عالم المهارات»** في الصفحة الرئيسية، بحيث تبدو كل مهارة لعبة مستقلة ويمكن فتحها مباشرة.
- تحسين بطاقات المهارات في بوابة الطالب لتشبه الألعاب التعليمية.


## إضافات V1.4
- إعادة ترتيب الصفحة الرئيسية لتصبح أوضح وأجمل على أول ظهور.
- إبراز راشد وبسمة مع الحفاظ على مساحة متوازنة للعنوان والبوابات.
- إضافة قسم «محطات مميزة» لثلاث مهارات مطورة: قطار الأنماط، برج القيمة المنزلية، جسر المقارنة.
- تطوير «قطار الأنماط» كمشهد بصري بعربات قطار.
- تطوير «جسر المقارنة» كمشهد بصري يضع فيه الطالب رمز المقارنة.
- تحسين عام لبطاقات الألعاب والمحطات لتشبه الألعاب التعليمية أكثر.


## إضافات V1.5
- **تجديد بوابة الطالب بالكامل** بدل تعديلات جزئية.
- بطاقة افتتاحية جديدة أكثر طفولية مع راشد وبسمة، وإحصاءات سريعة ومؤشر للمسار الحالي.
- مسار واضح داخل بوابة الطالب: **أفهم → أجرّب → أتدرّب → أتحدّى → إتقاني**.
- بطاقة **«محطتي المقترحة»** لتوجيه الطالب إلى المهارة التالية المناسبة.
- إعادة بناء **شاشة المهارة** لتصبح عالمًا طفوليًا ملونًا لكل مهارة.
- تبويبات داخل المهارة تحولت إلى بطاقات رحلة أوضح للأطفال.
- تحديث **بطاقة الإتقان** لتصبح أقرب إلى شارة إنجاز فيها نجوم وكأس.
